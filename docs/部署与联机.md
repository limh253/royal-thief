# 部署与联机（公网可玩）

目标：**任何人点开一个链接就能玩**——单机不用后端，双人用邀请码，不需要自己长期开着服务器。

## 二、两种联机方式（界面完全一样，自动选）

打开游戏 → 主界面 → **联机对战** → 「创建房间」拿到 4 位邀请码 → 把链接发给朋友。

| | 免服务器中继（默认） | 自建后端 |
| --- | --- | --- |
| 需要什么 | 什么都不用，公共 MQTT 中继 | 一台长期在线的服务器（Railway / Render / Fly / 自己的 VPS） |
| 谁算牌 | **房主的浏览器**跑权威引擎 | 服务器跑权威引擎 |
| 地址栏 | 留空 | 在「联机服务器」里填 `https://你的后端域名` |
| 适合 | 发链接就能找人开局 | 想要更严格的身份校验、更多人在线 |

### 免服务器中继是怎么工作的

- 房主点「创建房间」时，**房主自己的浏览器**里跑的就是 `src/room.js` 那套一模一样的房间内核（发牌、脱敏、判负都是同一份代码），所以**对手的手牌、牌堆、背水一战一样看不到**。
- 两人的浏览器通过公共 MQTT broker（`broker.emqx.io` → `test.mosquitto.org` → `broker.hivemq.com` 依次尝试）互相转消息，用的主题是 `royal-thief/v1/<邀请码>/…`。中继只转发，不存牌局。
- 客机只发「我要出这张牌」这类指令，收到的永远是**属于自己座位的那份脱敏快照**。
- **边界**：邀请码就是房间钥匙。知道邀请码的人能拿到自己那份快照、能提交自己的指令（朋友之间开局够用）。要更严格就用自建后端。
- 中继库（`mqtt.min.js`）是**点联机时才加载**的，单机完全不碰它，所以单机是零外部依赖。

### 自建后端（可选）

后端就是仓库里的 `server.mjs`（零依赖 Node），前端在「联机服务器」里填它的地址即可，前后端**不需要同域**。

云平台都已经给了现成配置：

| 平台 | 配置 | 说明 |
| --- | --- | --- |
| Railway | `railway.json` + `Dockerfile` | 部署完给你 `https://xxx.up.railway.app` |
| Render | `render.yaml` | free 计划会休眠，第一个访问要等十几秒 |
| Fly.io | `fly.toml` | 已设 `auto_stop_machines = false`，不休眠 |

**要点**

- 平台会注入 `PORT`，`server.mjs` 已经读它，不用改代码。
- 房间状态在内存里 → **必须只跑 1 个副本**（`railway.json` / `fly.toml` 已写死）。要多副本得先把房间状态挪到 Redis。
- 跨域：默认 `RT_ALLOW_ORIGIN=*`（放行任何来源）。想收紧就设成 `RT_ALLOW_ORIGIN=https://limh253.github.io,http://localhost:8787`。
- 项目走 **HTTP + SSE**（不是 WebSocket），所以前端里填的地址是 `https://…`。直接粘 `wss://…` 也行，`web/server-url.js` 会自动换成 `https://`。
- 健康检查：`GET /healthz`；`.github/workflows/keepalive.yml` 每 10 分钟打一次，防免费平台休眠（需要在仓库变量里设置 `RT_SERVER`）。

### 部署到 Cloudflare Pages / Netlify（只发前端）

`dist/site/` 整个文件夹就是完整站点（`index.html` + `mobile.html` + `vendor/mqtt.min.js`），直接拖上去即可：

- Cloudflare Pages：构建命令留空，输出目录填 `dist/site`（或直接把文件夹拖进「上传资产」）
- Netlify：拖 `dist/site` 到 app.netlify.com/drop
- 任何静态托管 / Nginx：整个文件夹丢进去

放上去之后，**单机立刻能玩，双人用免服务器中继**，不需要任何后端。

## 四、常见问题

**打开链接一片空白 / 按钮点不动**
多半是直接用 `file://` 双击了 `web/index.html`（浏览器不允许 `file://` 加载 ES 模块）。用 `dist/site/index.html` 或跑 `node server.mjs`。

**点了「创建房间」但朋友进不来**
1. 确认朋友点的是**邀请链接**，或者手输的 4 位邀请码没输错（已去掉容易看错的 I/O/0/1）。
2. 房主的页面要保持打开——免服务器模式下**房主就是服务器**，房主关了房就散了。
3. 公司网络 / 校园网可能挡掉公共 MQTT 的 WebSocket 端口；换个网络，或改用自建后端。

**「连不上联机中继」**
说明三个公共 broker 都没连上。检查网络；或先在主界面填上自建后端地址再开房。

**手机能玩吗**
能。把链接发到手机上打开即可；`mobile.html` 是触屏版（竖屏/横屏都适配）。想「像小程序一样」加到主屏，用浏览器菜单里的「添加到主屏幕」。

**想改成自己的域名**
GitHub Pages 仓库 Settings → Pages → Custom domain；或把 `dist/site` 传到自己的静态托管再绑域名。
