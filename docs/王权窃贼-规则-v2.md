# 《王权窃贼》完整规则 v2（含 2026-09 决议修订，可直接复制）

双人回合制卡牌博弈游戏，两名玩家：玩家 A、玩家 B。总卡牌共 28 张。

## 一、全局固定规则

1. **皇冠限制**：任何方式获得皇冠（抽牌、卡牌交换、战斗夺取、卡牌返还、不出战惩罚），如果手牌已经拥有皇冠，新拿到的皇冠直接送入弃牌堆。一名玩家手牌最多只能持有 1 张皇冠。
2. **皇冠溢出必须公开提示**：只要发生皇冠溢出弃置，双方都会看到提示「XX 皇冠超出上限，直接弃入弃牌堆」。（本次新增）
3. **弃牌堆不可回收**：卡牌一旦进入弃牌堆，本局不再重新使用。
4. **功能牌全局唯一且一次性**：每种功能牌本局仅有一张，打出后立刻放入弃牌堆，本局不能再次打出同一张功能牌。
5. **功能牌不可转移**（本次新增）：功能牌不能被「不出战惩罚」抢夺，也不能被「推心置腹」交换。若一方手牌只剩功能牌，则不出战惩罚对其无效（不夺牌）。
6. **信息隐藏**：除特殊写明外，功能牌执行完成只提示「结算完成」，不告知本次操作是否命中目标，不能用来推断对手手牌。
7. **对手手牌数量默认隐藏**：玩家只能看到自己手牌，以及对手手牌「是否已空」。背水一战不会向对手泄漏任何信息。
8. **背水一战仅自己可见**：判定结果只提示当前玩家，对手不会收到任何提示。
9. **手牌归零判负**：任何时刻玩家手牌变为 0 立刻判负。**唯一例外**：出战卡牌已离开手牌、尚未结算返还/弃置的窗口内不判负（否则背水一战机制无法使用）；该窗口结束、卡牌归位后再校验。抽牌阶段本身不可能导致手牌归零，故不再设「刚抽牌不触发」的例外。
10. **功能牌作用范围**：任何功能牌都不能作用于已经锁定、亮出的出战卡牌，只能作用于对手的手牌。

## 二、卡牌清单（共 28 张）

- 人牌（12 张）：人（善）×6，人（恶）×6
- 道具牌（9 张）：武器 ×6，皇冠 ×2，隐身衣 ×1
- 功能牌（7 张，每种仅 1 张）：洞若观火、重整、颠倒是非、铸剑为犁、推心置腹、沉默、止戈

## 三、游戏初始化

1. 将全部 28 张卡牌放入主牌堆，充分洗牌打乱顺序。
2. 玩家 A 抽 4 张作为初始手牌，玩家 B 抽 4 张作为初始手牌。抽牌过程中触发皇冠限制规则（若第 2 张皇冠出现，直接进弃牌堆，可能出现初始手牌不足 4 张的情况）。
3. 弃牌堆初始为空。
4. 沉默标记：双方初始均未被沉默。
5. 止戈计数器：初始为 0。
6. 回合数：初始为第 1 回合（A 的回合 + B 的回合 = 1 个完整回合）。

## 四、回合流程

玩家 A 先行动，之后玩家 B 行动，循环往复。单个玩家的回合严格按顺序执行：
抽牌阶段 → 能力牌阶段（双方同时暗置）→ 背水一战判定 → 对抗宣告阶段（双方同时暗置）→ 战斗结算阶段 → 回合结束阶段。

### 1. 抽牌阶段
- 主牌堆有牌：从顶部抽 1 张加入手牌，触发皇冠限制。
- 主牌堆已空：跳过抽牌。

### 2. 能力牌阶段（双方同时暗置）
- **本阶段不是「只由当前回合玩家出牌」，而是双方各有一次出牌机会**：两边各自私下选一张手牌中的功能牌（或跳过），提交后不可更改；双方都提交后，按 A → B 的顺序依次结算。
- 提交顺序：当前回合玩家先提交，再轮到对手提交。轮到谁提交，谁的屏幕上就弹出「请打出一张能力牌」。
- 若某位玩家处于被沉默状态：该玩家本阶段自动视为「跳过」，不能打出任何功能牌。沉默标记在能力牌阶段开始前清除。
- 对手是否会出牌、出了什么、有没有被沉默，都要等结算时才会体现在公开信息里（提交动作本身只产生一条「X 已提交本回合能力牌」的公开提示，不泄漏内容）。
- 否则二选一：不打出功能牌；或打出最多 1 张自己手牌中的功能牌。打出的功能牌立即移入弃牌堆。

功能牌效果：

| 功能牌 | 效果 |
| --- | --- |
| 洞若观火 | 对手手牌为空则无效果。否则随机选取对手 1 张手牌，只展示给当前玩家，本回合内可回看；对手看不到结果。 |
| 重整 | 从**整个剩余牌堆中随机抽取一张人牌**加入自己手牌，其余卡牌位置不变。牌堆中已无人牌则无效果。只告知抽到的卡牌，不提示牌堆剩余数量。 |
| 颠倒是非 | 对手手牌为空则无效果。否则**随机抽取对手 1 张人牌并翻面**（善↔恶，只翻这一张）。对手手牌没有人牌则无效果。只提示「结算完成」。 |
| 铸剑为犁 | 对手手牌为空则无效果。否则随机移除对手 1 张武器（进弃牌堆）。对手没有武器则无效果。只提示「结算完成」。 |
| 推心置腹 | 当前玩家自选 1 张**非功能牌**手牌，系统随机选取对手 1 张**非功能牌**手牌，两张交换归属。任一方没有可交换的非功能牌则失败，仅提示「结算完成」。交换成功双方都能看见这两张牌；交换后双方都执行皇冠限制。 |
| 沉默 | 标记对手下一回合进入沉默状态。打出者知道沉默施加成功；对手在其下一回合能力牌阶段收到提示「你本回合被沉默」，并被自动跳过。 |
| 止戈 | 跳过背水一战判定、对抗宣告、战斗结算，直接进入回合结束阶段。止戈计数器 +1（上限 2）。打出者知道止戈生效。 |

### 3. 背水一战判定（仅自己可见）
- 触发条件：当前玩家手牌数量等于 1，且这唯一一张牌是人牌。
- 满足条件且本回合选择出战时，获得临时变身：人（善）→ 骑士，人（恶）→ 匪徒。效果持续到本回合结束；选择不出战则不获得变身。
- 仅剩道具牌或功能牌时不触发。
- 该判定只影响自己，对手不会收到任何提示，也无法借此得知你的手牌数量。

### 4. 对抗宣告阶段（同时暗置 → 同时亮出）
- 双方各自秘密选定本回合宣告，提交后不可修改（锁定）；双方全部提交后一次性同时亮出，再进入战斗结算。
- **出战硬性要求**：出战组合必须包含人牌，两种形式：① 单独 1 张人牌；② 人牌 + 1 张道具牌（武器/皇冠/隐身衣）。
- 手中没有人牌的玩家无法出战，只能选择不出战。
- 出战：出战卡牌从手牌取出，暂时离手，**该窗口内不触发手牌归零判负**。
- 不出战：不展示手牌。惩罚：对手随机拿走该玩家手牌中的 1 张卡牌（功能牌除外；若无合法目标则不夺牌），拿到的卡牌执行皇冠限制。

### 5. 战斗结算阶段
只有双方都出战才执行战斗结算。

1. **贼效果优先结算**：若任一方出战组合为人牌 + 隐身衣，弃掉隐身衣（进弃牌堆），夺取对方出战组合里的武器（收入自己手牌，执行皇冠限制）。
2. **身份判定（锁定瞬间冻结）**：身份在出战组合提交锁定时即已计算完成并冻结，之后弃隐身衣、夺武器都不回溯修改本次战斗的身份。

| 出战组合 | 身份 |
| --- | --- |
| 单人善 / 单人恶 | 普通人 |
| 人善 + 武器 | 骑士 |
| 人恶 + 武器 | 匪徒 |
| 人 + 皇冠 | 国王 |
| 人 + 隐身衣 | 贼 |
| 背水一战出战（单人善） | 骑士 |
| 背水一战出战（单人恶） | 匪徒 |

3. **克制关系**：骑士克匪徒、普通人；匪徒克国王、普通人；国王克骑士；普通人克国王；**贼无克制，对任意身份均为平局**。无克制关系即平局。
4. **胜负处理**：胜者二选一（选择仅胜者本人可见，败者只能看到卡牌最终变化结果）：
   - ① 保留自己的出战卡牌，对手的出战卡牌送入弃牌堆；
   - ② 弃掉自己的出战卡牌（进弃牌堆），将对手的出战卡牌收入自己手牌（执行皇冠限制）。
   - **禁止**胜者选择会导致自己手牌归零的处理方式。
5. **平局**：双方出战卡牌**全部送入弃牌堆，不返还手牌**；弃置后立即执行手牌归零判定（双方同时归零判平局）。（注意：贼的隐身衣已在第 1 步弃掉、夺得的武器已入手，都不参与本步弃置。）
6. **只有一方出战**：跳过战斗结算，出战卡牌原样返还手牌（执行皇冠限制）；不出战方按第 4 节接受惩罚。

### 6. 回合结束阶段
- 清除本回合所有临时状态（背水一战变身、宣告记录、探查回看记录、出战区）。
- 若本回合没有打出止戈，止戈计数器立刻清零。
- 终局判定（见第六节），未结束则切换至另一名玩家回合。

## 五、止戈计数器

- 语义：记录本回合是否有止戈生效。任一方打出止戈则该回合计数 +1；若某个回合双方都没打出止戈，计数在回合结束阶段清零。
- 终局条件：**主牌堆为空 且 止戈计数器 ≥ 1** → 游戏结束，按双方手牌数量结算（多者胜，相同则平局）。即：**主牌堆见底之后，谁打出止戈谁就停战结算**——手牌多的一方可以借此锁定胜利。
- 为什么阈值是 1 而不是 2：止戈全局只有 1 张、打出后立刻进弃牌堆、本局不再获得，「连续两个玩家回合各打出一次止戈」永远不可能发生，原阈值 2 是死条款。降为 1 之后该条款变成真实可用的战术（实测随机对局约 1.8% 走到这个终局）。

## 六、胜负判定（按优先级）

1. 任何时刻一方手牌归零 → 该方立刻判负（出战卡牌离手窗口除外）。
2. 双方同时手牌归零 → 平局。
3. 主牌堆为空且本回合有止戈生效（止戈计数器 ≥ 1）→ 按手牌数量结算。
4. 主牌堆为空后，连续 3 个完整回合内所有战斗全部平局、未产生任何胜负结果 → 立刻停止，按双方当前手牌数量结算（3 为可调参数）。
5. 达到全局回合上限 40 个完整回合 → 按双方当前手牌数量结算。
6. 手牌数量相同 → 平局。

## 七、边界规则补充
- 出战卡牌只能是人牌，或人牌 + 单张道具；功能牌不能参与出战组合。
- 被拿走卡牌、交换卡牌、战斗获取卡牌、不出战惩罚，所有「获取卡牌」的场景都必须校验皇冠上限；平局改为弃牌，不涉及获取，无需校验。
- 平局弃牌会实打实减少手牌，因此平局也可能直接分出胜负（一方因此归零即判负，双方同时归零则平局）。
- 背水一战只在对抗宣告前判定一次；不出战则不产生变身；变身不保留到下一回合。
- 沉默标记只影响下一个回合的能力牌阶段；被沉默者在该阶段无法打出止戈，因此止戈计数器会被清零（该策略效果保留）。

## 八、本次修订清单（相对原版）
1. 对抗宣告改为「双方同时暗置提交 → 同时亮出」，消除后宣告者的信息优势与跨回合挂牌问题。
2. 「贼」身份在锁定时冻结，明确贼无克制、对任意身份平局（修复原版「人+隐身衣=贼」是被弃掉后的死规则、且克制表缺失贼的问题）。
3. 出战卡牌离手期间豁免手牌归零判负（修复原版会导致背水一战永远无法使用、且单人出战即判负的冲突）。
4. 补全「只有一方出战」时的出战牌返还规则。
5. 止戈计数器语义统一（背靠背 +1、上限 2、主牌堆空时结算）。
6. 功能牌增加「不可转移」标记。
7. 明确手牌归零的四种触发场景；禁止胜者选择会导致自己手牌归零的选项。
8. 重整改为「从剩余牌堆随机取一张人牌」，其余卡牌不动。
9. 新增「牌堆耗尽后连续 3 回合无胜负」僵局兜底与「40 回合」全局上限。
10. 皇冠溢出公开提示；颠倒是非明确为翻一张；善恶差异写入正文（双人组合生效）；删除冗余的「刚抽牌不判负」条款；探查结果本回合可回看；沉默标记清除时机明确；补充双方同时归零判平局。
11. **平局改为双方弃牌**：平局不再返还手牌，双方出战卡牌直接进弃牌堆（含参战的皇冠），并立刻做手牌归零判定。这会显著提高对局烈度（实测手牌归零终局从 70.0% 升到 94.4%），如需回调把 `RULES.drawDiscardsBattleCards` 设为 `false` 即可恢复原「返还」规则。
12. **止戈终局条款改为可执行**：止戈保持全局 1 张（牌组仍为 28 张），终局阈值由「连续两次背靠背」降为「主牌堆见底时打出 1 次止戈即停战结算」，消除死条款。

## 九、待你确认的遗留问题
1. ~~止戈终局条款不可达~~ **已解决**：止戈保持 1 张、牌组仍为 28 张，通过把 `RULES.zhiGeGoal` 降为 1 让条款可执行——主牌堆见底时打出止戈即停战结算（实测随机对局约 1.8% 走到）。若想恢复「连续两个玩家回合各打出一次止戈」的原语义，把 `RULES.zhiGeCopies` 改为 2（牌组变 29 张）并把 `zhiGeGoal` 改回 2 即可。
2. **手牌数量是否公开**：当前默认隐藏（与「背水一战不泄漏手牌数量」一致）。若改为公开，需同步删掉背水一战的隐私条款。
3. **同时宣告模型下不出战惩罚的覆盖面**：当前按原规则字面执行——双方都宣告，因此**非行动方**选择不出战同样会被夺牌，这会让手牌消耗速度明显变快（每回合双方都必须「出战或掉牌」）。若希望缓和，可改为「只有行动方的不出战才受惩罚」。
